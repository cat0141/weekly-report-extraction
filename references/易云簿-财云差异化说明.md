# 易云簿与财云差异化说明

> **关键文档**：产品线提取前必须阅读。避免产品线混淆。

---

## 产品定义

| 产品 | 目标客户 | 典型客户举例 |
|------|---------|-------------|
| **易云簿** | 终端企业客户（自己用财务软件的） | 各类中小企业 |
| **财云** | 代账公司 / 财务机构（给别人做账的） | 代账公司、会计师事务所 |

---

## 归类规则

### 归入财云的信号
- 出现 **"AI会计师"** → 财云（是财云升级版，不是易云簿功能）
- 出现 **"专业版"** → 财云（是财云的版本体系，不是易云簿版本）
- 客户是 **代账公司 / 财务机构** → 财云
- **四川一新泽** → 财云客户

### 归入易云簿的信号
- 客户是 **终端企业**（非代账公司）
- 未出现以上财云关键词

### 待确认的情况
- **独立标题下的内容**：如"售前技术支持"作为独立一级标题（不在"易云簿项目"下面），未明确标注产品线时 → **标注"待确认"**，不能默认归到当前产品线
- **合计数据无法拆分**：如"本周回款 2.41 万"同时包含两条产品线的业务 → **不提取**，不放入单产品线文档
- 其他无法判断的情况 → 标注"待确认"，**不要猜测**

## 提取检查清单

逐条提取时，必须回答：

1. [ ] 这条内容属于哪个产品线？（易云簿 / 财云 / 待确认）
2. [ ] 判断依据是什么？（客户名称 / 关键词 / 上下文）
3. [ ] 是否已排除另一条产品线？（确认不是财云功能 / 确认不是易云簿功能）
4. [ ] 如果无法判断，是否已标注"待确认"？

## 反模式

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 看到客户名字自动归到当前讨论的产品线 | 必须查差异化文档确认 |
| 假设"AI会计师"是易云簿功能 | AI会计师 = 财云升级版 |
| 独立标题下的内容默认归属上一级 | 独立标题需单独判断归属 |
| 合计数据强行拆分 | 无法拆分则不提取 |
| 周报涉及多产品线时只提取一个 | 全部提取不要漏 |
