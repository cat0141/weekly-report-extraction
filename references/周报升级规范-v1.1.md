# 周报 v1.1 升级规范

> 大王 2026-05-11 要求。当大王说"升级周报"、"周报不能是流水账"、"写周报 vX.X 版本"时，必须遵循此规范。

---

## 核心原则

1. **禁止纯流水账** — 不只是罗列数据，每条数据后必须带分析/判断/建议
2. **以目标为导向** — 开头放"本月目标 vs 当前进度"对比表，所有数据围绕"差多少"展开
3. **必须有上周工作总结** — 放在文档第一部分，总结做了什么、进展到哪一步
4. **必须写"数据缺失清单"** — 列出各渠道/各人下周必须填报的具体项（打勾框格式），明确标注谁缺什么，否则无法支撑业务判断

---

## 文档结构

```
一、上周工作总结
  - 回款与销售
  - 线索获取
  - 数据口径统一进展
  - 其他重要事项（内容营销、产品迭代等）

二、数据 vs 月度目标
  - 目标进度总览（目标、累计、进度、差距）
  - 五渠道漏斗（按渠道拆分，标注"待补充"项）

三、数据缺失清单（下次必填）
  - 按人/按渠道列出缺失项，用 [ ] 打勾框
  - 示例：
    ### 葛玉（渠道1 付费 + 渠道2 免费）
    - [ ] 投流视频"主页始终可见"是否已执行？
    - [ ] 免费渠道本周线索量、有效线索量各多少？

四、业务分析
  - 每个关键数据段带分析判断，指出风险和机会

五、本周行动项
  - 表格格式：任务 | 负责人 | 优先级 | 说明

六、下周关注
```

---

## 重要规则

| 规则 | 说明 |
|------|------|
| **先写本地再发** | 保存先写服务器本地，不直接建飞书/钉钉文档 — 大王确认后再发 |
| **用 doc-link-by-path 获取链接** | 手机可直接访问 |
| **不要发消息到群里收集信息** | 如果数据不全，直接在文档里写"还缺什么"，作为下次数据收集的规范 |
| **格式适配手机** | 飞书沟通优先列表/纯文本，避免大表格 |

## 汇总输出格式

在汇总文件中追加 `## YYYY-MM-DD 本周（MMDD-MMDD）` 区块，包含：

```markdown
### 💰 业绩
- 徐航：新签 X 单（Y 易云簿 + Z 财云），回款 X 万
- 汪玉瑶（运营组）：易云簿收款 X 元
- 葛玉（投流）：投流花费 X 元，新增线索 X 条（有效 X 条）

### 📈 投流与线索数据
- 有效线索目标：X，完成 X%
- ROI 目标值：X，完成 X

### 💡 产品需求（一线反馈）
- 需求1
- 需求2

### 📋 运营
- 运营事项1
- 运营事项2

### 🧠 关键思考
- 思考1

### 📅 下周计划
- 徐航：...
- 葛玉：...
- 王顺泽：...
```
